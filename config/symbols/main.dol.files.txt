# main.dol — source-file attribution (GGSPA4, PAL)
#
# NOT names. These are functions whose SOURCE FILE is established from the
# binary itself: each hands its own `__FILE__` and `__LINE__` to Konami's
# tracked allocator in sd_mem.c, so the file it was compiled from - and the
# exact line the call sits on - are in its instruction stream. The companion
# file for the engine overlay is mgso_pal.rel.files.txt.
#
# WHAT THIS ESTABLISHED, beyond the per-function attribution: main.dol is not
# only SDK and CodeWarrior runtime. It carries Konami's own sound layer
# (sd_sound.c, sd_stream2.c, sd_mem.c, sd_ogg.c) and a complete Tremor -
# the Xiph fixed-point Vorbis decoder - in codebook.c, floor0.c, floor1.c,
# framing.c, info.c, mapping0.c, res012.c, sharedbook.c, vorbisfile.c and
# block.c. That block is 198 functions and about 34 KB, all of it previously
# unattributed, and it is what the engine's audio calls reach.
#
# CROSS-CHECK. Within every one of the nine Tremor/ogg translation units the
# line numbers run STRICTLY DOWNWARDS as the address rises - CodeWarrior
# emitted those units in reverse order of definition - while the four Konami
# sd_*.c units run strictly upwards. Nine files monotonic in one direction
# and four in the other is not something a mis-parse produces; it is the
# check that these line numbers are being read correctly.
#
# The line numbers do NOT match upstream Tremor: framing.c line 864 is inside
# ogg_stream_pagein upstream, and here it allocates 80 bytes. Konami edited
# these files - replacing Xiph's allocator with their own tracked one, among
# other things - so upstream line numbers cannot be used to put NAMES to
# these addresses, and none are claimed here.
#
